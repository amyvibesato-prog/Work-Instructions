# Робочі інструкції (Desktop App)

Настільний додаток для Windows (Electron + React + TypeScript) для створення, редагування, збереження та перегляду поетапних робочих інструкцій із фотографіями та вкладеннями.

## Можливості ПК-версії
- **Спільне файлове сховище (локальне або в мережевій папці `\\Server\Share`)**: кожна інструкція зберігається в окремому файлі з крос-комп'ютерними блокуваннями (`locks/`), контролем конфліктів версій, індикацією присутніх редакторів (`presence/`) та спільним журналом аудиту (`audit/`).
- **Оптимізоване зберігання фото та вкладень**: медіафайли винесені в окрему папку `assets/` за SHA-256 хешем (без дублювання та розбухання JSON).
- **Фіксація папки серверного збереження та резервних копій**: вибрані шляхи зберігаються в налаштуваннях ПК і працюють після перезапуску чи оновлення.
- **Експорт у PDF та автономний HTML**: нативне системне вікно «Зберегти як…» (`printToPDF`) та прямий друк.
- **Необов'язкові оновлення з GitHub Releases**: користувач може відкласти оновлення, пропустити версію або встановити у зручний час через **Налаштування → Оновлення**.

## Команди
- `npm run dev` — запуск у режимі розробки
- `npm run test:storage` — автотести файлового сховища та багатокористувацьких блокувань
- `npm run build` — збірка інтерфейсу та Electron-процесів
- `npm run dist` — створення інсталятора `.exe` у папці `release/`
- `npm run release` — збірка та публікація нової версії в GitHub Releases
